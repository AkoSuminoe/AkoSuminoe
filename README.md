## About Me

I'm a BEng Software Engineering student at the **University of Westminster** (2024–2028), based in London, building a foundation across Python, Java, JavaScript, and SQL. My coursework spans Object-Oriented Programming, Database Systems, Machine Learning & Data Mining, and Algorithms — theory, design, and implementation.
